One funny single-line excuse a developer gives when code breaks in production,
71 characters:

> A user did exactly what the button said to do. We never tested that.

The joke: it starts as blame-the-user — the user followed the instructions —
then collapses into a confession in the second sentence. The happy path
itself was never tested, which is the twist every developer recognises
instantly. No "works on my machine", no staging, no load-bearing anything:
the field is full of those, and this angle appears in none of the 533
entries' titles.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`),
byte-identical on every run. Python 3.13, standard library only, no network.
